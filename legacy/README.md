# legacy/

Files from earlier attempts at this project, kept because they record how it started, and
because deleting something that turns out to be load-bearing is worse than a folder nobody
opens. Nothing here is referenced by the build, the app, the tests or CI.

| File | What it was | Why it is not used |
|------|-------------|--------------------|
| `main.js`, `preload.js`, `package.json` | An Electron prototype of the simulator - a browser window with the circuit drawn in JavaScript | The project is a native C11 / SDL2 application. Nothing in `src/` or `meson.build` refers to any of them, and only they refer to each other |
| `CMakeLists.txt` | The original build | Superseded by `meson.build`, which is what every build, the release script and both CI workflows use |
| `component_search.png` | A screenshot of an early component-search UI | Nothing links it. The current screenshots live in `screenshots/` (hand-picked) and `screenshots/auto/` (regenerated by `tools/make_media.py`) |

## What stayed at the top level, and why

- `screenshot.png` - the README's title image
- `guide.html` - shipped in the release zip and uploaded by CI
- `icon.ico` - embedded by `app.rc`; `icon.bmp` - loaded at runtime by `src/app.c`
- `ui_layout.json` - `tools/ui_editor.c` opens it by that name from the working directory
- `build.bat`, `rebuild.bat`, `rebuildandrun.bat`, `run.bat` - still current: they call
  `meson setup` / `meson compile`, not the old build
